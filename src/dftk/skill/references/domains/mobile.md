# Mobile evidence

Common claim families include contacts, SMS/messages, calls, media, app databases, transfers, links/QR payloads, account/session data, and timelines.

Preserve application/container identity. Correlate records using stable IDs, conversation/thread IDs, transaction/message IDs, and timestamps rather than display text alone.

For “uploaded without consent” claims, distinguish stored local data, read access, prepared request data, transmission path, and actual network/runtime evidence.
