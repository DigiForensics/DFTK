# Reporting

## Competition / question-answer format
Preserve numbering. Lead with the exact answer.

```text
5. <answer>
Status: VERIFIED
Evidence: <source> — <locator>
Reasoning: <one or two sentences connecting the evidence to the question>
```

If unresolved, say so instead of guessing.

## Investigation finding
For each material claim:
- claim/question;
- conclusion;
- verification level;
- evidence source + locator + value/finding;
- source hash/method when available;
- reasoning chain;
- material limitation.

## What not to report as evidence
- your own hypothesis;
- a tool name without its result;
- a command you intended to run;
- unsupported/error output as proof of absence;
- a guessed path/record ID/hash;
- hidden reasoning or internal planning text.

## Reproducibility
When useful, include the DFTK capability name and relevant parameters, but evidence provenance matters more than a long command transcript.
